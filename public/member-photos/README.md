# عکس‌های اعضای تیم رَسا

عکس‌های پرتره‌ی چهار عضو تیم که در کارت‌های اعضا نمایش داده می‌شوند. این فایل‌ها داده‌ی پشتیبان محلی (`src/data/fallbackData.ts`) هستند و در `photo_url` هر عضو با مسیر نسبی `./member-photos/...` ارجاع شده‌اند؛ در صورت اتصال به Supabase، عکس بارگذاری‌شده در میز مدیریت (`rassa-member-media`) اولویت دارد.

| فایل | عضو |
| --- | --- |
| `mojtaba.jpg` | مجتبی میدانی |
| `mohammad.jpg` | محمد صحرانورد |
| `abolfazl.jpg` | سید ابوالفضل میرزازاده |
| `alireza.jpg` | علیرضا حاجی‌زاده |

برای جایگزینی، کافی است فایل هم‌نام را با عکس جدید (ترجیحاً مربعی یا عمودی) جایگزین کنید.
