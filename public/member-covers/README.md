# تصویرسازیِ کارگاه‌های رَسا

این پنج تصویر با هوش مصنوعی و برای سربرگ کارت‌ها ساخته شده‌اند. هیچ‌کدام پرتره یا عکسی از محل کار واقعی اعضا نیستند.

| تصویر | کاربرد |
| --- | --- |
| `planning` | دفتر زمان‌بندی پروژهٔ مجتبی میدانی |
| `mobile` | نمونه‌سازی اپلیکیشن محمد صحرانورد |
| `data` | سرور و پایگاه دادهٔ سید ابوالفضل میرزازاده |
| `editorial` | میکروفن و برگه‌های ارائهٔ علیرضا حاجی‌زاده |
| `studio` | دفتر کار خنثی برای صندلی معرفی‌نشده یا نقش تازه |

برای هر طرح دو سربرگ WebP با عرض ۷۵۶ و ۱۴۰۴ پیکسل و یک برش کوچک `thumb` برای فهرست وجود دارد. قاب‌ها بر پایهٔ **نقش فعلی** عضو انتخاب می‌شوند. عکس شخص فایل جداگانه‌ای است که از `members.photo_url` می‌آید؛ اگر عکس در دسترس نباشد نشانِ حروف اول نام جای آن را می‌گیرد.
