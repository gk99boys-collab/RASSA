# موسیقی پس‌زمینهٔ رَسا

فایل صوتی قابل انتشار را با نام دقیق **`Khorasani.mp3`** همین‌جا قرار دهید: `public/music/Khorasani.mp3`. حرف اول نام بزرگ است؛ اگر ویندوز پسوند را مخفی کرده، `.mp3` را دوباره به نام اضافه نکنید.

با آپلود روی `main` و پایان انتشار GitHub Pages، پخش‌کننده بدون تغییر کد فعال می‌شود. تا زمانی که فایل وجود نداشته باشد، دکمه‌ای نمایش داده نمی‌شود و سایت هم درخواستی برای آهنگ نمی‌فرستد.

سایت عمومی پیش از آماده‌شدن React و اینترو، پخش با صدا را درخواست می‌کند. آهنگ در صورت اجازهٔ مرورگر هنگام ورود پخش و تکرار می‌شود؛ پنل مدیریت موسیقی ندارد. اگر پخش خودکار مسدود باشد، سایت با اولین لمس، کلیک یا فشردن کلیدی که مرورگر به‌عنوان تعامل کاربر بپذیرد، دوباره تلاش می‌کند. اسکرول به‌تنهایی اجازهٔ پخش صدا نمی‌دهد. دکمهٔ بلندگو در سربرگ برای پخش و مکث است و انتخاب مکث برای بازدید بعدی حفظ می‌شود.
